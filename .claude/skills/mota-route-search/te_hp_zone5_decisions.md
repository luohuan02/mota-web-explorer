# zone5 决策逻辑（2攻全防 / TE HP 路线，钥匙-金币-掉血权衡）

本文档记录 **2攻全防线**（`best/zone12_2atk6def_39944_walk.json`）在 zone5（MT41-50，项目脚本里叫
「zone4」）的**逐决策权衡逻辑**，格式同 `te_hp_zone1_decisions.md`。zone5 是**终局**：魔龙战、
防商店 funding、魔法场、终战前资源闭环。这里的每一项决策都直接决定最终 HP，且大多已经
**结构性封闭 / funding-critical**（见 `te_hp_optimization_experience.md`「结构性封闭杠杆」+
「末段防商店 funding-critical」）——本文件把这些决策与翻面条件落到逐条，供「还有没有可翻面
的」探查。

## 通用原则（贯穿 zone5 决策）

- **掉血口径**：用 `dmg` 增量；`checkBlock` 地图伤害（魔法场/火）也是 HP 成本。
- **funding 阶梯**：末段金币的边际价值**不连续**——「能凑够下一档防商店 funding 阈值的金」
  值 ~1.58 HP/G，超出的 stranded ~0。所有「多凑 100G / 省 100G」的决策都要按此判。
- **魔龙 DEF 陡坡**：pre-dragon DEF=592 → 魔龙 1336 伤；DEF 599 → 167（+7 DEF 省 1169 血）。
  但 39944 已买满 13 次防商店 + 全部 pre-dragon 防宝石 + MT2 specialTrader，**592 已 hard-cap**。

## Z5-D1：MT45 魔法场 1200（结构性不可避）

**决策**：step803-810 4 次穿越 MT45 魔法场（checkBlock 300×4=1200，@DEF290）。
**理由**：MT44 是隐藏层（`HIDDEN_FLOORS={"MT44"}`，`:next/:before` 跳过），只能经 upFly 到达；
upFly 道具在 MT45 左侧 (2,10) 魔法场后，取它必须 4 次穿场，且 upFly 从 MT45 直上到 MT46 而非
MT44，必须回 MT43 才能用→返回再穿。**1200 HP 结构性不可避免**。
**翻面**：**无**。唯一可降是 DEF（魔法场是 300 固定，非比例）——已 max（DEF290 时 300，DEF 更高
也 300，因为不是按 DEF 算的固定 checkBlock）。

## Z5-D2：MT44 神圣盾（+100 DEF，magicImmune）

**决策**：经 upFly 进隐藏层 MT44 拿神圣盾（step815，DEF 290→390，+100 DEF，`magicImmune=True`）。
**理由**：+100 DEF 是最大单次属性提升，也是 magicImmune（后续魔法无效）；拿完应把
`__auto__.item` 切回 `true`（4 区半血陷阱后不再怕魔法）。
**翻面**：**无**——神圣盾是 5 区核心里程碑，+100 DEF 直接压低魔龙 + 后续怪伤。

## Z5-D3：MT46 防商店（最后 5 次，DEF 395→575，funding-critical）

**决策**：step840-978 买满 5 次 MT46 防商店（DEF 395→575，花 ~8000G）。
**理由**：MT46 防（+20/次，ratio5）是 highest-value HP 来源，尤其 near-dragon（DEF 陡坡）。
**翻面（funding 关键）**：**最后一个 MT46 防商店（step978，2120G，DEF 555→575）funding-critical**——
靠 step973-976 MT28 卖 4 yk（+400G，G 1773→2173）才买得起；没有它魔龙 DEF 停在 572，伤 4676 vs
1336，**多 3340 血**。所以**最后的 4 把 yk 值 ~835 血/把**（不连续，只在 funding 阈值上成立）。
⇒ **任何「少卖一把 yk / 多花 100G 在别处」都可能让最后一个防商店买不起 → 损失 3340 血**。
这是 zone5 唯一的高敏感点，改动前必须重算 funding 阶梯。

## Z5-D4：魔龙（1328 @ DEF592，DEF 陡坡 hard-cap）

**决策**：step982 打 MT35 魔龙（1328 伤 @ATK259 DEF592）。
**理由**：魔龙→雪花→MT13 熔岩→+100 ATK 剑是**循环闸门**，魔龙必须在 ATK=259（拿 +100 剑前）打；
所有 zone-4/5 ATK 宝石都已在魔龙前收。DEF 592 已 hard-cap（见「通用原则」）。
**翻面**：**无**（结构性 + 已 max）。魔龙 1336 是当前路线固定下界；唯一理论上限是「追 +7 DEF 到 599」
（省 1169 血），但需找到漏收防宝石——目前无来源。

## Z5-D5：MT2 specialTrader（+17 DEF +8 ATK）时机

**决策**：step980 MT2 特殊商人，+17 DEF（575→592）+ 8 ATK（251→259），恰在魔龙前。
**理由**：+17 DEF 把魔龙伤压到 1336（若无它，592-17=575，魔龙 4175 伤，多 2839 血）；是魔龙前的
**最后一块 DEF**。
**翻面**：**无**——必须魔龙前拿（魔龙后才拿的 DEF 救不了魔龙战）。

## Z5-D6：终局消费排序（防商店 > hp2000 > keyBundle+蓝瓶 > 2420）

**决策**：终局消费顺序 = 防商店（~1.58 HP/G）> MT45 hp2000（1000G，+2000 血，0.5 HP/G 但一次性必买）
> MT31 keyBundle+散落蓝瓶（1000G→4YK+1BK→收 +800×5 蓝瓶，~3.2 HP/G）> MT46 2420 商店（0.66 HP/G，不买）。
**理由**：skill 对照 38624 vs 39003：等量金币投 keyBundle+收蓝瓶（3.2 HP/G）通常优于 2420 商店
（0.66 HP/G）。39944 已收 keyBundle+全部蓝瓶（step1031 买 keyBundle31 → step1032-1042 收蓝瓶，
HP 31184→32634，+1450），2420 商店因 G=1207<2420 不可凑款。
**翻面**：若某线能凑 `≥2420+1000+1000=4420G`，则 2420 商店 + hp2000 + keyBundle 三者兼得
（+1600 商店 + 蓝瓶 +2000），压过当前。这是**唯一未封闭的终局方向**（见 te_hp_optimization_experience.md 点 3）。

## Z5-D7：MT47 地震卷轴时机（4000G）

**决策**：step793 花 4000G 买地震卷轴（假魔王线结构性必需），时机在 zone4-5 初凑够金后。
**理由**：地震是 TE 假魔王封印/路径必需；4000G 是最大单笔开销，早买早用（清 0 伤怪批处理）。
**翻面**：与「先地震后防商店 vs 先防后地震」的金币流顺序有关——若先买防商店导致凑不够 4000G，
顺序要调（见 skill「金币节奏」）。39944 先凑 4000G 买地震（step793），再买防商店。

## 40943 线 zone5 变体（门少开 all-def，2026-08-23 web 已验证）

这是**突破 39944 的新一族**（`best/2区2攻+买800rk+1yk换100血的门少开+4区全防纯净版TE-40943_walk.json`，
final HP=40943 ATK=374 DEF=607 gold=640 MT50，5 区 MT41→MT50 走 349 步，dmg=2860）。
它**逃出了 39944 族的「无路到 41477」结论**（那些结构性封闭建立在 39944 金币流上）。zone5 走法与
39944 不同，核心是两个新增的资金杠杆 + 一条不同的终局消费序：

- **Z5-40943-A：41F 起步吃资源养关键配置**。从 save105（MT41 HP43 ATK146 DEF266 YK10 BK1 G3031）起步，
  zone5 前段把 41F 附近可达 + 魔龙后的资源吃满（圣剑/神圣盾/龙对策），为 MT46 防商店 funding 蓄力。
- **Z5-40943-B：MT28 卖 10 把 yk 是防商店 funding 主力**。比 39944（只卖 4 把凑最后一档 2120G）多卖
  k 倍——40943 walk 在 zone5 末段分两批卖 yk：step78-83 `3411→4011`（6 把）、step263-266
  `1760→2160`（4 把），共 **+1000G**，直接喂 15 次 MT46 防商店（DEF→607）。**这是 40943 能溢出 39944
  +999 血的核心**：zone2「门少开」省下的 yk 在 zone5 变现成防商店资金。⇒ 与 [[zone2_2atk_recording_experience]]
  的「+2YK at MT31」首尾呼应：少开门省 yk → 期末卖 yk → 更高 DEF → 全场减伤。
- **Z5-40943-C：终局消费序不同**。40943 **不买** 2420 商店（资金仍 <2420，D6 的「凑 4420G」在
  此族也职未达），也不买 keyBundle（蓝瓶已替）：尾段只买 **MT45 hp2000（1000G，step337 `1140→140`）**
  + 地震卷轴(4000G，MT47) + 防商店，终局 gold=640 stranded。**核心差异 = 防商店踩到 DEF607 比
  39944 的 592 更高**，故 dragon 伤更少、终局 HP 更高。
- **Z5-40943-D：去掉 39944 的 MT44 隐藏层神圣盾取线依赖**。40943 用红钥匙路线 + 龙对策替代，省掉
  39944 那段昂贵 upFly 回返；神圣盾仍拿但走法不同（42/47 对称飞行器）。

**剩余状态选项（用户手打，对应 40943 线 zone5 可操作点）**——这些是「终局还有没有可翻的正收益
资源」的候选，多数已被 40943 walk 收敛（yk 全卖、金尾 640 stranded），逐项：

| 剩余转化 | 内容 | 40943 walk 是否已用 |
|---|---|---|
| 34F 8yk → 4yk+1RK+214G | 需先凑 +46G 够 214 差额 | **否（不可用）**：walk yk 全卖=0，MT34 仅 upFloor 通过 |
| 33F 1BK → 1yk+75G | 蓝钥匙换黄钥+75G | **否（不可用）**：final bk=0 |
| 16F 1YK → 20G+100HP | yk 换金币+血 | **否（不可用）**：final yk=0 |
| 11F 1YK → 39G+100HP | 同上 | **否（不可用）**：final yk=0 |
| 8F/3F 1YK → 50HP+3G | 黄钥换血 | **否（不可用）**：final yk=0 |

> **关键：40943 walk 终局 yk=0、gold=640（stranded，MT50 redKing +500）**。10 把 yk 全卖 MT28
> （4011→4000 地震 + 2160→末档防商店）。上方「yk→血+金」转化因此全不可用。唯一仍可翻的门 =
> **在城乡保留 1-2 把非 funding-critical 的 yk 走「单钥→血+金」**（11F 1yk→39G+100HP、8F/3F
> 1yk→50HP+3G）：条件是那把 yk 卖出后【仍够】最后一档防商店 + 地震 4000G，否则卖是必须。这是一把
> yk 从「stranded 100G」变「100HP+39G」的净正，是 40943 冲 41477（差 434）候选主攻。

> **这些「yk → 血 + 金」转化是 40943 线剩余微操的主攻方向**：40943 把 yk 全卖了（MT28 100G/把），
> 但如果某把 yk 在「不饿死防商店 funding」的前提下能换成「血 + 金」净正收益，就是免费 +HP。
> 判定 = 该 yk 是否**非 funding-critical**（卖出后仍够最后一档防商店）：非 critical 的 yk 走
> `单钥换血+金` 比卖 100G 更赚（100HP+金 > 100G）。这是 40943 冲 41477（当前差 41477−40943=**434**）
> 最可能的微操落点——详见 [[te_hp_2420_funding_analysis]] 的「微优化封顶」延伸。

## 41228 族四线终局账本封闭证明（2026-09-06 量化，模拟全否决）

对 41200/41228/41218/40145 四条录像线做全账本对账（起点 7G + 收入 − 支出 = final 零误差，
**四线支出同为 20220G**；收入 20352-20853）+ 用 converter 权威重放做改线模拟（shop patch /
动作重排），把所有「可能提升」逐一量化否决：

1. **def→hp 换档**（MT46 六档防 8920G 换 hp 档，理论 +7500）：模拟 **-8651**。根因 =
   终局两场马拉松战的 def 联动——魔龙（atk600/def250，hero atk 259 → hero_hit 9 →
   **167 回合**）damage=166×(600−def)；大法师（560/310）**91 回合** damage=91×(560−def)；
   **圣水 = round(0.74×(atk+def))×10**（items.js）→ 1 def ≈ 166+91+7.4 ≈ **257 HP**。
   静态悬崖表（zone5 怪 def≥431 全 0 伤）会误判「MT46 防无用」——**悬崖判定必须含
   魔龙/大法师 marathon 与圣水联动**，这是本证明的核心教训。
2. **魔龙悬崖 +664**（41228 族魔龙战 def=596，差 4 到 600）：全部 +4def 来源被依赖链
   封锁——MT49 蓝宝石(+15) 在封印段内（specialDoor 封路，楼梯口绕行模拟不可达）；
   「魔龙移到 knife 后」重排在公主事件断链（**雪花是 MT26 熔岩门硬前置**：
   魔龙→雪花→公主→50F 小偷→49F 封印→knife 刚性链）；MT2 祝福事件以 `hide` 收尾
   **live 一次性确认**（specialTrader 类但 hide 了）。金链也锁死：剑士 270G 是地震
   4000G 资金一部分，地震揭 MT37 宝石(+16atk) 又是魔龙可杀性前提（atk 259−16=243
   < 龙 def 250 → 不可杀）。
3. **MT40 三剑士 1326 伤**：剑士 hp100/atk680/def50 → 2 回合战 damage=680−def 一次反击，
   **atk≥150 → 1 回合秒杀 0 伤**。但 atk 池化被金链锁死（地震 4000G 在剑士战时只有
   3596，剑士自己的 270G 是 farm 一部分）；跳过剑士房则 +12atk 丢失 → 魔龙 247<250
   不可杀。剑士房 sweep 是 load-bearing。
4. **MT45 法术场 1200**（upFly 行程 4 次穿场）：走廊向导预杀模拟 **-518**——pre-49F
   atk 259 下向导战是马拉松（288+530），且法术场是多向导叠加（杀两只后返程仍 -300）。
5. **keyBundle / 残余怪金 / 4 红瓶**：权威重放剩余 items 仅 4 红瓶+1yk（全门封死，
   终局插取模拟 +0）；残余怪金 385-786G 不够 n17 hp 档 2740。
6. **40145 过 MT42 陷阱纪律**：血瓶粒度 200 > 需要的 ~119，压到 16 必死。

**结论**：41228 族录像的终局架构（15 档阶梯 + MT28 卖钥桥 + 魔龙/大法师/封印金链）在
同 seed 收入上限内**已榨干**，每个表面浪费都被 atk/def 悬崖格或金链锁死。后续搜索不应
再投入这四个方向；zone1-3 微优化是唯一未系统性重搜的区块（参见官方 41477 差距 249）。
